Ozark of Austin -- deploy folder for oatreeservice.com.

Everything here is generated. Do not edit by hand; it is overwritten.

Build and deploy:
  cd build && python3 build.py
  cd .. && node qa.js            # must report 0 failing
  rsync -a --delete --exclude .git site/ preview-deploy/
  cd preview-deploy && git add -A && git commit && git push

CNAME and .nojekyll are emitted by build.py on purpose -- the rsync
deletes anything the build does not produce.
